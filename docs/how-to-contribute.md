# How to contribute (no coding needed)

It is completely fine if you have never written code or used the command line.
This project is mostly about **collecting and labeling receipt images** — data
work that is a perfect job for non-coders. Developer tooling comes later.

## Ways to help

1. **Submit data** — privacy-checked receipt photos you have the right to share (see `DATA_GUIDELINES.md`).
2. **Help annotate / review labels** — labeling what you see on an image (see `ANNOTATION_GUIDELINES.md`).
3. **Improve documentation** — simpler wording, examples, corrections.
4. **Share ideas** — open an issue or post in Discussions. No format required.
5. **Review** — read proposed changes and give friendly feedback.

## No Git? No problem — use the GitHub website

You can do most things from your browser, no tools to install:

- **Open an issue** — click the `Issues` tab → `New issue` and pick a template.
- **Edit a file** — browse to a file, click the pencil (✏️) icon, make your
  change, enter a short message, and choose "Create a new branch... and start a
  pull request" → `Propose changes`.
- **Upload a file** — click `Add file` → `Upload files`, then follow the same
  commit steps.
- **Discuss** — use the `Discussions` tab to ask questions or talk about ideas.

## Privacy is rule number one

- No card numbers, names, addresses, or signatures in the images.
- Redact anything personal before submitting.
- Never guess a label — if you can't read it, mark it `unreadable`.

## If you do code

- Fork → branch → change → pull request (details in `CONTRIBUTING.md`).
- Keep changes small and easy to review; add tests when you add features.

## What reviewers check

- No secrets or personal data
- Content is real — never invented data or labels
- Guidelines are followed (`DATA_GUIDELINES.md`, `ANNOTATION_GUIDELINES.md`)
- Files are in the right folders

Ask for help any time — friendly questions are always welcome.

## A quick note on Hacktoberfest 2026

Hacktoberfest 2026 works differently from earlier years: **pull requests no
longer count** toward rewards. Instead, 2026 is about **building with
open-source AI and open-weight models**, and participants earn virtual stickers
by attending Fests, joining livestreams, taking part in DEV Challenges, and
using tools (3 stickers = a sticker pack in the mail).

So: contribute to this repo because it is genuinely useful and fun — and to win
at the Fest, **submit on the day following the Fest's own rules** (one teammate
opens the Challenges tab on the event page, adds the submission, selects the
challenges, and submits before the host's deadline). The host picks winners
from the day's projects and demos.

_Source: DevRelay knowledge base, verified 2026-09-30 against
hacktoberfest.com._

# START HERE 👋 (2-minute guide)

**What this repo is:** collecting receipt photos + a written label for each
(merchant, date, total...) so we can later train AI to read receipts.

## 1) See it working (10 seconds)

```bash
python src/preprocessing/structure_check.py
```

_Output: a report of the dataset folders. Nothing to install._

## 2) Help in 3 steps — NO coding, NO Git needed

1. Open the **Issues** tab.
2. Pick any issue with the **`beginner`** or **`good first issue`** label.
3. Comment **"I'll take this"** and follow the 2-3 lines in the issue.

That's it. The easiest one:

- `#1` — **share one receipt photo** (your own, personal details hidden).
  That's literally it — tap "Add file → Upload files" on the GitHub website.

## 3) What if I'm stuck?

- Post in the **Discussions** tab — someone will answer, no question is dumb.
- No receipt handy? Pick `#3` (improve the label list) — it's just writing.
